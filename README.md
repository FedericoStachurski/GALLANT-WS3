# GALLANT Work Package Areas
------

### Overview
This dataset is a a visual geospatial representation of the regions of Glasgow where different GALLANT work packages are focusing their research.
It has been created by the GALLANT team and is a resource for researchers to use.

### Accessing the Data
To access this dataset - please request access to the files that you require. Once your access request is approved you will be able to download the files from this page - https://gallantdatahub.ubdc.ac.uk/datasets/1

### Citing the Dataset
When citing the GALLANT Work Package Areas dataset in academic or research contexts, use the Harvard referencing style:
GALLANT (2023). GALLANT Work Package Areas [Dataset]. Retrieved from https://gallantdatahub.ubdc.ac.uk/datasets/1

### Get in Touch 
If you have any questions or would like to contribute to the dataset or this README file, please post a comment or email gallant-support@glasgow.ac.uk. We are always eager to hear from users and incorporate their feedback into future updates of the dataset.
